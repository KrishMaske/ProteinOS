# Exercise dataset and media notice

ProteinOS normalizes structured exercise data from [`hasaneyldrm/exercises-dataset`](https://github.com/hasaneyldrm/exercises-dataset). The dataset repository identifies its structured content as MIT-licensed.

Exercise media is intentionally stored behind replaceable `image_source`, `gif_source`, and `media_id` fields. Media does not automatically inherit the application or dataset code license. The upstream repository attributes visual assets to Gym Visual and includes separate terms in its `NOTICE.md`.

Before publishing, redistributing, caching, or monetizing exercise images/GIFs, review the upstream notice and obtain any license required for the intended use. Removing or replacing media URLs does not affect routine or workout-history records because those records reference stable exercise IDs.
